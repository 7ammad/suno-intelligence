# Creator workflow

## 1. Start anywhere meaningful

A creator can begin from one of six entry paths:

1. **Reference study** â€” abstract attributes from a song, artist, or scene and
   transform them into an original direction.
2. **Genre, tradition, or instrument exploration** â€” investigate a musical
   question with context and respect.
3. **Original instrumental** â€” begin from movement, rhythm, bass, texture, or
   emotional arc.
4. **Vocal/lyric-led song** â€” begin from words, voice, language, and prosody.
5. **Creator-owned seed** â€” develop a melody, voice note, stem, lyric fragment,
   or unfinished track.
6. **Hybrid collision** â€” intentionally connect two or more worlds with a
   clear musical bridge.

## 2. Build the brief

The system asks the useful questions: what should the listener feel, what holds
time, what owns the low end, what changes across the track, what must not happen,
and what makes this combination specific?

## 3. Generate

Until official developer access exists, the creator takes the brief to Suno
manually. An authorized API could later make this handoff and result capture
direct, but it never replaces the creator's decision.

## 4. Listen and decide

After each result, the creator records one of three outcomes:

- **Keep** â€” what is worth preserving?
- **Change** â€” which musical role, emotional promise, or arrangement move needs
  a different direction?
- **Reject** â€” what failed, in plain language?

The note improves the next brief. It does not silently retrain a model or erase
creative history.

## 5. Build the world around the track

For a selected track, define the visual world, cover, hook/short, release
rhythm, community invitation, and platform adaptations. The same underlying
composition brief keeps them coherent.

## 6. Learn without chasing noise

Owned-account analytics and listener reactions are evaluated alongside the
creator's own listening decision. A strong metric is a question to investigate,
not an order to flatten the music into whatever performed last week.
