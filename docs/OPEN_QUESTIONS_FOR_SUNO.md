# Open questions for Suno

This proposal is designed to work manually. These questions would help creators
understand where an official integration could fit.

1. Is there a path for an individual creator to apply for developer access, or
   is access currently limited to selected partners?
2. Which creator-authorized operations could an official API support: creation,
   status, retrieval, cover artwork, extend/remix lineage, library metadata, or
   other workflow steps?
3. Can a creator attach external metadata or a versioned creative brief to a
   generation for their own later retrieval?
4. What permissions and retention rules apply to a creator's generations and
   metadata when a third-party tool is authorized?
5. Is there a supported way to retrieve creator-owned performance or library
   signals without automating the consumer UI?
6. What review, rate-limit, and product constraints should a serious creator
   tool be designed around?

We would rather build within a clear official boundary than guess at one.
