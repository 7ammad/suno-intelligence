# Creator craft guide

Suno Intelligence is a creator-first system for inventing music worlds instead of chasing generic prompts or artist imitation.

## The operating loop

1. Start with one listener promise and one productive tension: weight/air, closeness/distance, restraint/release, warmth/metal, or another clear contradiction.
2. Assemble roles from the semantic library: temporal grammar, bass, rhythm, harmony, motif, form, texture/material, and a voice cast or a strict instrumental constraint.
3. Generate a canonical composition brief. The Suno prompt is its short working translation, not the source of truth.
4. Select the Suno feature intentionally: Custom creation for a whole world; Editor/Replace Section for a local repair; Voices/Add Vocals for a creator-owned central voice; Sounds for unfamiliar materials; Hooks for the strongest social moment; Custom Models for a recurring personal sound built from owned tracks.
5. Generate manually, retain the candidate link, and record the exact prompt, model, controls, output, listening verdict, one success, one failure, and one next change.
6. Promote only observed patterns into reusable craft knowledge.

## Prompt language

A short Suno instruction has five jobs:

```text
[listener promise]. [bass + rhythm foundation]. [two or three material roles].
Arrangement: [opening] -> [turn] -> [peak] -> [exit].
[vocal behavior OR exact instrumental constraint].
```

Give every element a job—low anchor, answer, transition, or release texture—and name when it enters or exits. Avoid adjective piles and named artists. For instrumentals, be explicit: `no lead vocal, chant loop, spoken phrase, or filler syllables`.

## Lyrics and original voice casting

Build lyrics from an original speaker, emotional turn, concrete image system, section jobs, short hook, and one chosen voice role. A cast is register + grain + delivery + distance + density + interaction; it is never a celebrity resemblance.

Use a creator-owned verified Voice or owned-track Custom Model when the product feature is available. The semantic cast remains useful before and after that: it describes the artistic job rather than copying a person.

## Repairing generic or strange vocals

| Symptom | First repair |
| --- | --- |
| random syllables / “wop wop” | make that section instrumental, or supply exact short lyrics and a clear-diction instruction |
| unwanted singer in an instrumental | use Instrumental mode; name instrument roles; explicitly exclude lead vocal, chant, speech, and filler syllables |
| generic singer | choose a concrete cast; specify register, grain, delivery, phrase length, and entry point |
| ad-libs/crowd chant | define the peak instrumentally and exclude automatic ad-libs/crowd chant |
| muddy pronunciation | shorten the line and repair only the affected section |

Change one named field per repair. A good trial isolates a real musical hypothesis rather than regenerating blindly.

## What the public library contains

- musical possibility: rhythm, bass, harmony, melody, form, instrument roles, texture, production space, and relationship logic;
- human identity: original voice casts, lyric behavior, creator-owned voice routes, and original sound-source ideas;
- Suno craft: official capability map, trial protocol, prompt-to-brief method, and artifact repair;
- output memory: versioned briefs, candidate references, listening decisions, accepted masters, cover/hook/publishing references, and community response.

It intentionally contains no copied melodies, raw third-party audio, artist-voice targets, credentials, or unverifiable “prompt secrets.”
