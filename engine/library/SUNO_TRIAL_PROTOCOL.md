# Suno trial protocol

Every manual Suno attempt produces one `trial-record` object. The record is a creative memory, not a scorecard.

1. Begin from the canonical composition brief.
2. Record the exact model or mode, prompt, lyrics mode, and controls.
3. Preserve output links or external references; do not copy media into this library.
4. State the listening decision in plain language.
5. If an artifact appears, name its time range and the next specific change.
6. A prompt intervention becomes a reusable Suno observation only after more than one dated result supports it.
